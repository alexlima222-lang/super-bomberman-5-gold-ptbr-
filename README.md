# Super Bomberman 5 Gold Cartridge — Tradução PT-BR

Projeto independente de tradução para português brasileiro de **Super Bomberman 5 Gold Cartridge (SNES/Super Famicom)**.

## Situação
Em desenvolvimento e revisão. Os checkpoints citados na documentação não são lançamentos finais e ainda precisam de conferência técnica antes da publicação.

## Objetivos
- Traduzir menus e textos preservando a jogabilidade.
- Manter **MÁQUINA** no menu de regras, conforme preferência atual do projeto.
- Revisar menus, OPTION e Battle Mode.
- Corrigir problemas de texto sem introduzir falhas gráficas ou travamentos.

## Estrutura
- `docs/`: histórico, plano de testes e problemas conhecidos.
- `patches/`: local para patches IPS **verificados**.
- `scripts/`: local para ferramentas próprias revisadas.

## Aplicação de patches
1. Utilize sua própria cópia legalmente obtida da ROM japonesa compatível.
2. Preserve uma cópia de segurança da ROM original.
3. Confira os hashes e a base exigida nas notas de cada patch.
4. Aplique o IPS com ferramenta compatível, sem empilhar patches salvo instrução explícita.
5. Teste a ROM resultante no emulador ou hardware de sua preferência.

**Nenhum patch IPS está incluído neste pacote inicial.**

## Direitos autorais
Não distribuímos ROMs nem outros arquivos comerciais do jogo. Super Bomberman e seus elementos originais pertencem aos respectivos titulares. Projeto não oficial.

## Relatar problemas
Informe a versão do patch, hash da ROM-base, emulador e versão, passos para reproduzir e, se possível, captura de tela.
